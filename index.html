Project02COMPUTER VISION

IT Stress Detection System

What it doesA Django web application that captures a user’s face and classifies facial expressions into seven categories. Negative emotional patterns are used as possible indicators of stress for IT professionals—not as a medical diagnosis.

How it worksOpenCV converts each camera frame to grayscale and locates the face with a Haar Cascade. The cropped region is resized to 48 × 48 pixels, then passed to a Keras CNN for emotion prediction. Trained weights are loaded from an H5 file, avoiding retraining at application startup.

Application

Django provides user and admin modules; OpenCV and Keras handle the recognition pipeline.
